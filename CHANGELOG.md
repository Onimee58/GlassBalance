# Changelog

## v0.2.0-alpha — Visual redesign preview

### Added
- Modernized native Qt sidebar, stat cards and overview hierarchy.
- Balance trend plot based on the last 90 recorded transaction balances.
- About screen with project creator, repository and MIT attribution.

### Changed
- Cleaner tab styling, typography, colors and ledger layout.
- Application version changed to `0.2.0-alpha`.

### Unchanged
- Local SQLite database schema, opening balance and transaction behavior.
- Original/curated Excel and CSV import/export and encrypted manual email backup.

### Important
- Preview only. Back up your ledger before installing.
- Windows GUI and cross-distro Linux still need hands-on verification.
