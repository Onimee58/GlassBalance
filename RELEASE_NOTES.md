# GlassBalance v0.2.0-alpha

An early preview of the new native desktop design, rebuilt around a balance overview, an in-app native trend chart and a simpler navigation experience. Existing ledgers remain compatible.

**Creator and founding maintainer:** [@Onimee58](https://github.com/Onimee58)

**Upgrade:** Back up your ledger from v0.1 first. Install/run v0.2 on the same computer and it will use the existing local database. Do not reimport data unless starting on a new computer.

**Testing:** All eight core ledger tests pass. The Qt GUI could not be launched in the source-generation environment; please validate visually on Ubuntu before publicly attaching builds. Automatic two-way sync is not part of this alpha.
